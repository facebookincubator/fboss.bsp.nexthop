# Contributing to fboss.bsp.nexthop

We welcome contributions to the Nexthop board support package for FBOSS.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Describe the problem and your proposed changes in the pull request.
3. Add or update tests for code changes, and update documentation for changes to
   supported platforms, configuration, or build and installation steps.
4. Run the available checks and include their results. For hardware changes,
   include the switch model, kernel version, and tests run on the switch.
5. Follow the style of the surrounding code. Linux kernel code should follow the
   [Linux kernel coding style](https://www.kernel.org/doc/html/latest/process/coding-style.html).
6. Complete the Contributor License Agreement if you have not already done so.

The repository is being initialized. Build and hardware test instructions will
be documented alongside the BSP implementation.

## Contributor License Agreement (CLA)

To accept your pull request, we need you to submit a CLA. You only need to do
this once to contribute to Meta's open source projects.

Complete your CLA at <https://code.facebook.com/cla>.

## Issues

Use GitHub issues for bugs and feature requests. Include enough information to
reproduce a bug, along with relevant platform details and logs. Remove secrets
and private information before submitting.

For security vulnerabilities, use
[Meta's bug bounty reporting process](https://bugbounty.meta.com/) and do not
file a public issue.
